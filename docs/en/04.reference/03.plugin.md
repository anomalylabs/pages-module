# Plugin

<div class="documentation__toc"></div>

## Pages

### page

The `page` function returns a decorated page instance for a given `identifier`. Value arguments are page IDs, paths, or compatible class 

```twig
{{ page('/about/company').title }}
```

### structure

The `structure` method returns a navigation menu based on the page structure and configuration.
 
```twig
{{ structure()
    .linkAttributesDropdown({'data-toggle': 'dropdown'})
    .listClass('nav navbar-nav navbar-right')
    .childListClass('dropdown-menu')
    .render()|raw }}
```

#### Caching

The `structure` method accepts the standard plugin criteria `cache` option:

    {{ structure().cache(3600).render()|raw }}

Pages can be restricted to roles with their **Allowed Roles** field, so the result depends on who is
viewing. The cache key therefore includes the viewer's roles automatically - anonymous visitors share
one entry, and signed-in viewers share an entry with everyone holding the same roles. A structure
cached for one audience is never served to another.

> A structure containing restricted pages is cached per audience, so expect one cache entry per
> distinct set of roles rather than one overall.{.notice}
